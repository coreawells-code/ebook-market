# ebook-market

전자책 마켓플레이스. Next.js (App Router) + TypeScript + Tailwind CSS 기반.

## 시작하기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 |
| `npm start` | 프로덕션 서버 실행 |
| `npm run lint` | ESLint 검사 |

## 현재 상태

`create-next-app` 기반 초기 구조만 잡혀 있습니다. 도메인 기능(도서 목록, 상세, 장바구니, 결제 등)은 아직 구현 전입니다.
